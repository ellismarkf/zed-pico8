# Pico-8 grammar for Tree-sitter

Based on https://github.com/tree-sitter-grammars/tree-sitter-lua

## Features

- Full Pico-8 Lua dialect, as documented at https://pico-8.fandom.com/wiki/Lua
- Full P8 format documented at https://pico-8.fandom.com/wiki/P8FileFormat
- Syntax highlighting, locals, and tags in the [queries folder](queries)
- Some P8 examples in the [examples folder](examples)
